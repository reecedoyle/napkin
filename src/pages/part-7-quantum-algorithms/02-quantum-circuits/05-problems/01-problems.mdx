  difficulty="standard"
  prompt="The Fredkin gate (also called the controlled swap, or CSWAP gate) is the three-bit reversible gate that swaps the last two input bits whenever the first (control) bit is 1, and leaves all three bits unchanged when the control bit is 0. Show that the Fredkin gate is reversible and universal."
  hint="One approach: construct the CCNOT (Toffoli) gate using a few Fredkin gates. Toffoli is universal, so this suffices."
  solution="Reversibility: the Fredkin gate is its own inverse — applying it twice restores the original input, since swapping twice is the identity. So it is a bijection on its input space. Universality: we show the Fredkin gate can reversibly implement a Toffoli (CCNOT) gate. Writing Fred(a, b, c) for the gate that swaps b and c when a = 1, the sequence (z, ¬z, −) = Fred(z, 1, 0); (x, a, −) = Fred(x, 1, 0); (y, b, −) = Fred(y, a, 0); (−, c, −) = Fred(b, 0, 1); (−, d, −) = Fred(c, z, ¬z) yields d = z ⊕ xy (mod 2), which is exactly the CCNOT output. Since Toffoli is universal for reversible classical computation, the Fredkin gate is also universal."

<Problem
  client:load
  id="qcirc-prob-no-clone"
  difficulty="standard"
  prompt="Baby no-cloning theorem. Show that there is no unitary map U on two qubits satisfying U(|ψ⟩ ⊗ |0⟩) = |ψ⟩ ⊗ |ψ⟩ for every qubit |ψ⟩. In other words, no circuit can clone an arbitrary unknown qubit."
  hint="Plug in |ψ⟩ = |0⟩, then |ψ⟩ = |1⟩, then |ψ⟩ = |x₊⟩ = (|0⟩+|1⟩)/√2, and derive a contradiction using linearity of U."
  solution="Suppose such a unitary U existed. Then U(|0⟩ ⊗ |0⟩) = |00⟩ and U(|1⟩ ⊗ |0⟩) = |11⟩. Now apply U to |x₊⟩ ⊗ |0⟩ = (1/√2)(|0⟩+|1⟩) ⊗ |0⟩. By linearity of U, U(|x₊⟩ ⊗ |0⟩) = (1/√2)(U(|0⟩⊗|0⟩) + U(|1⟩⊗|0⟩)) = (1/√2)(|00⟩ + |11⟩). But if U were a cloner we would need the output |x₊⟩ ⊗ |x₊⟩ = (1/2)(|00⟩+|01⟩+|10⟩+|11⟩). These two states are different — (1/√2)(|00⟩+|11⟩) ≠ (1/2)(|00⟩+|01⟩+|10⟩+|11⟩). Contradiction."
/>

<Problem
  client:load
  id="qcirc-prob-deutsch-jozsa-general"
  difficulty="standard"
  prompt="Deutsch-Jozsa (general n). Consider the following circuit for the general Deutsch-Jozsa algorithm: take n copies of |0⟩, apply H to each, apply the oracle U_f (which acts on n+1 qubits), apply H again to the n input qubits (discarding the last), then measure all n bits. Show that the probability of measuring |0…0⟩ is 1 if f is constant and 0 if f is balanced."
  hint="First show that U_f sends |x₁⟩⊗…⊗|x_m⟩⊗|x₋⟩ to (−1)^(f(x₁,…,x_m)) times itself. Then track what happens to the superposition created by H^(⊗n)."
  solution="Let |x₋⟩ = (1/√2)(|0⟩−|1⟩). The oracle acts as U_f(|x⟩⊗|x₋⟩) = (−1)^(f(x))|x⟩⊗|x₋⟩ — a phase kickback. Starting from |0…0⟩⊗|1⟩, after H^(⊗n+1) the state is (2^(−n/2))Σ_x |x⟩ ⊗ |x₋⟩. After U_f it becomes (2^(−n/2))Σ_x (−1)^(f(x)) |x⟩ ⊗ |x₋⟩. Discarding the last qubit leaves (2^(−n/2))Σ_x (−1)^(f(x)) |x⟩. Now apply H^(⊗n). Using H|x_i⟩ = (1/√2)Σ over y_i of (−1)^(x_i·y_i)|y_i⟩, the coefficient of |y⟩ is 2^(−n) Σ_x (−1)^(f(x)+x·y). At y = 0…0 this coefficient is 2^(−n) Σ_x (−1)^(f(x)). If f is constant this sum is ±1 (all signs agree), giving probability 1. If f is balanced, exactly half the signs are +1 and half −1, so the sum is 0, giving probability 0."
/>

Verify that the quantum Toffoli gate can be implemented using only controlled P and Q rotations (controlled one- and two-qubit gates) via the circuit in the source. This was a surprise: classical reversible logic requires genuine three-bit gates (Toffoli, Fredkin), but quantum mechanics allows decomposition into controlled two-qubit rotations."
  hint="This is a direct matrix computation. Track the effect of each gate on the eight computational basis states of the three-qubit space, and verify the output matches the Toffoli truth table."
  solution="This is a direct computation. The circuit decomposes as: (1) controlled-Q on qubits 2 and 3 (control: qubit 2); (2) controlled-Q on qubits 1 and 3 (control: qubit 1); (3) controlled-P on qubits 1 and 2 (control: qubit 1); (4) CNOT on qubits 1 and 2; (5) controlled-Q† on qubits 2 and 3 (control: qubit 2); (6) CNOT on qubits 1 and 2. Checking on each basis state |x₁x₂x₃⟩: when x₁ = x₂ = 1 the accumulated phases combine to flip qubit 3; otherwise they cancel to give the identity. The key identity is Q²P = (phase) × (flip), verified by matrix multiplication. The surprise is that this works with only two-qubit (and one-qubit) controlled gates, unlike the classical case where AND is irreducibly a two-bit-to-one function requiring a genuine three-bit gate to implement reversibly."
