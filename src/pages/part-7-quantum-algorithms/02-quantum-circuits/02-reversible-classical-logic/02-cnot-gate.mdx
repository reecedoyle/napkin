The most important reversible two-bit gate is the <Term k="cnotGate">CNOT gate</Term> (controlled-NOT).

<Callout kind="definition" title="CNOT gate">
The **CNOT gate** takes two bits $(x, y)$ and outputs $(x,\; x \oplus y)$, where $\oplus$ denotes XOR (addition mod 2). The first bit $x$ is the "control" — it determines whether the second bit gets flipped.

| In $(x, y)$ | Out |
|---|---|
| $(0, 0)$ | $(0, 0)$ |
| $(0, 1)$ | $(0, 1)$ |
| $(1, 0)$ | $(1, 1)$ |
| $(1, 1)$ | $(1, 0)$ |
</Callout>

The control bit $x$ passes through unchanged. The target bit $y$ gets flipped if and only if the control is $1$. Reversibility is clear: running CNOT twice returns the original input.

<Callout kind="example" title="CNOT simulates NOT">
CNOT can simulate NOT using one <Term k="ancillaBit">ancilla bit</Term> fixed at $1$. Feed in $(x, 1)$: the output is $(x, x \oplus 1) = (x, \text{not } x)$. So the bottom wire carries $\text{not } x$, and we can discard the top wire as a <Term k="garbageBit">garbage bit</Term>.
</Callout>
