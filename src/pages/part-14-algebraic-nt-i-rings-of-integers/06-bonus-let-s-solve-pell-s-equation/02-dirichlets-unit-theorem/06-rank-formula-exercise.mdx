<SlideLayout title="Computing the rank s">

The rank $s = r_1 + r_2 - 1$ is the key number. Let us practice computing it.

For a real quadratic field $K = \QQ(\sqrt{d})$ with $d > 0$ squarefree, both roots $\pm\sqrt{d}$ are real, so $r_1 = 2$, $r_2 = 0$.

<NumericInput
  client:load
  id="an58-dut-num-rank-real-quadratic"
  prompt="What is the rank s = r₁ + r₂ − 1 for any real quadratic field ℚ(√d) with d > 0?"
  expected="1"
  hint="r₁ = 2, r₂ = 0, so s = 2 + 0 − 1."
/>

For an imaginary quadratic field $K = \QQ(\sqrt{-d})$ with $d > 0$, there are no real roots, so $r_1 = 0$, $r_2 = 1$.

<NumericInput
  client:load
  id="an58-dut-num-rank-imag-quadratic"
  prompt="What is the rank s for any imaginary quadratic field ℚ(√−d) with d > 0?"
  expected="0"
  hint="r₁ = 0, r₂ = 1, so s = 0 + 1 − 1 = 0. Only roots of unity!"
/>

</SlideLayout>
