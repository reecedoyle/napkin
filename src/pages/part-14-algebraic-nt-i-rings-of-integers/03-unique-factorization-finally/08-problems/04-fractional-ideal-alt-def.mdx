  prompt="Let 𝒜 be a Dedekind domain with fraction field K, and pick J ⊆ K. Show that J is a fractional ideal if and only if: (i) J is closed under addition and multiplication by elements of 𝒜, and (ii) J is finitely generated as an abelian group. In other words: J is a fractional ideal iff J is a finitely generated 𝒜-module. Hint: clear denominators!"
  solution="(⇒) If J = (1/x)·𝔞 for x ∈ 𝒜 and 𝔞 integral, then J is an 𝒜-module (closed under 𝒜-multiplication) and finitely generated as an abelian group since 𝔞 is finitely generated and J = {(1/x)a : a ∈ 𝔞}. (⇐) Suppose J is a finitely generated 𝒜-module, generated by elements β₁/α₁, …, βₙ/αₙ ∈ K with αᵢ, βᵢ ∈ 𝒜. Set α = α₁···αₙ. Then αJ ⊆ 𝒜 (since α·(βᵢ/αᵢ) = (α/αᵢ)βᵢ ∈ 𝒜). Moreover αJ is finitely generated and closed under 𝒜-multiplication, hence an ideal 𝔞 of 𝒜. So J = (1/α)·𝔞, a fractional ideal."
