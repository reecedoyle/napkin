<SlideLayout title="Algebraic integers via finitely generated modules">

To show $\OO_K$ is closed under $+$ and $\times$, we use a clean characterization of algebraic integers.

<Callout kind="lemma" title="α ∈ Z̄ iff ℤ[α] is finitely generated">
Let $\alpha \in \ol{\QQ}$. Then $\alpha$ is an algebraic integer if and only if the abelian group $\ZZ[\alpha]$ (all polynomial expressions in $\alpha$ with integer coefficients) is <Term k="finGen">finitely generated</Term> as a $\ZZ$-module.
</Callout>

**Why this helps:**

- **Forward direction:** If $\alpha^N = c_{N-1}\alpha^{N-1} + \cdots + c_0$ (monic integer polynomial), then every power $\alpha^k$ can be reduced to a linear combination of $\{1, \alpha, \dots, \alpha^{N-1}\}$. So $\ZZ[\alpha]$ is generated by $N$ elements.
- **Backward direction:** If $\ZZ[\alpha]$ is generated by $b_1, \dots, b_m$ (polynomials in $\alpha$), then $\alpha^N$ for $N$ large enough can be expressed as $c_1 b_1(\alpha) + \cdots + c_m b_m(\alpha)$, giving a monic polynomial satisfied by $\alpha$.

</SlideLayout>
