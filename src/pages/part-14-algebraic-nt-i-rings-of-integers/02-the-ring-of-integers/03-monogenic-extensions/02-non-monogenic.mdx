The first counterexample to monogenicity is a degree-3 field.

<Callout kind="example" title="A non-monogenic cubic field">
Let $\alpha$ be a root of $f(x) = x^3 - x^2 - 2x - 8$, and set $K = \QQ(\alpha)$. The ring of integers $\OO_K$ is **not** monogenic — there is no single element $\theta$ with $\OO_K = \ZZ[\theta]$.

One can show that $\OO_K \cong \ZZ^3$ with $\ZZ$-basis $\left\{1, \alpha, \beta\right\}$ where $\beta = \frac{\alpha + \alpha^2}{2}$.
</Callout>

Why does monogenicity fail here? The group generated by $\{1, \alpha, \alpha^2\}$ has **index 2** in $\OO_K$: there are elements of $\OO_K$ (like $\beta$) that you cannot reach as integer combinations of $1, \alpha, \alpha^2$.

If instead you try $\{1, \beta, \beta^2\}$, the same index-2 problem persists: now $\alpha$ is missing. One can compute $\beta^2 = 3\beta + 2\alpha + 6$, so $\alpha$ is an integer combination of $\{1, \beta, \beta^2\}$ — but then $\beta^2$ generation re-introduces $\alpha$ and the cycle continues.

The extension is **not monogenic** because no single $\ZZ$-basis element generates all of $\OO_K$.

</SlideLayout>
