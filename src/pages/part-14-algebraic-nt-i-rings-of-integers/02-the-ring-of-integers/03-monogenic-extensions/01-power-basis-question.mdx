title: Can we always find a power basis?
---

<SlideLayout title="Can we always find a power basis?">

We know every number field $K$ can be written as $\QQ(\alpha)$ for a single element $\alpha$ (the Primitive Element Theorem). Naturally, we ask: can $\OO_K$ also be generated by a single element?

<Callout kind="question" title="Does 𝒪_K always have a power basis?">
Does there always exist $\theta \in \OO_K$ such that $\OO_K = \ZZ[\theta]$, with $\{1, \theta, \theta^2, \dots, \theta^{n-1}\}$ serving as both a $\QQ$-basis for $K$ and a $\ZZ$-basis for $\OO_K$?
</Callout>

If such a $\theta$ exists, we call the extension **monogenic**. The name comes from "generated by a single element."

This is true for the most common examples:
- **Quadratic fields** $\QQ(\sqrt{d})$: always monogenic.
- **Cyclotomic fields** $\QQ(\zeta_p)$: monogenic with $\theta = \zeta_p$.

But it is **not always true.**

</SlideLayout>
