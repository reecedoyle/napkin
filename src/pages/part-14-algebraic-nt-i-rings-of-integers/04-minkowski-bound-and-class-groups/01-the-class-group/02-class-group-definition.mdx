<SlideLayout title="The class group">

Since $J_K$ is abelian and $P_K \leq J_K$, we can form the quotient:

<Callout kind="definition" title="Class group Cl_K">
$$\Cl_K \defeq J_K / P_K.$$

The elements of $\Cl_K$ are called **ideal classes**. Two nonzero fractional ideals $\mathfrak{a}, \mathfrak{b}$ belong to the same class if and only if $\mathfrak{a} = (x)\mathfrak{b}$ for some $x \in K^\times$ — that is, they differ only by scaling by a field element.
</Callout>

<Callout kind="remark" title="Moral">
The class group $\Cl_K$ is the set of nonzero fractional ideals modulo scaling by a nonzero element of $K$. Think of classes as the "shapes" of ideals: two ideals in the same class are isomorphic as $\mathcal{O}_K$-modules.
</Callout>
