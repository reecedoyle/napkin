Mod 5: x²+4x+1 (irreducible — discriminant 12 is not a square mod 5), so (5) is prime. Each prime has norm 4, 9, 25 respectively; only (2) has norm ≤ M_K and it is principal. The only integral ideals of norm ≤ 6.5 are (1) and (2), both principal. Hence Cl_K is trivial and 𝒪_K is a UFD. Note: 163 is the largest Heegner number — the complete list of n for which ℚ(√−n) has class number 1 is {1, 2, 3, 7, 11, 19, 43, 67, 163}."
