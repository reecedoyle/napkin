  prompt="[Kronecker's theorem] Let α be an algebraic integer. Suppose all its Galois conjugates (including α itself) have absolute value exactly 1. Prove that αᴺ = 1 for some positive integer N."
  hint="Let α = α₁, α₂, …, αₙ be the conjugates. Look at the polynomial Pₑ(x) = (x − α₁ᵉ)⋯(x − αₙᵉ) across e ∈ ℕ. Pigeonhole on all possible polynomials."
  solution="For each positive integer e, form Pₑ(x) = (x − α₁ᵉ)⋯(x − αₙᵉ). Since each αᵢ is an algebraic integer and the Pₑ are symmetric in the conjugates, Pₑ has integer coefficients. Each |αᵢᵉ| = |αᵢ|ᵉ = 1, so the elementary symmetric polynomials in {α₁ᵉ,…,αₙᵉ} have absolute value at most C(n,k) (by the triangle inequality). The coefficients of Pₑ are bounded integers, so there are only finitely many possible polynomials Pₑ. By the pigeonhole principle, there exist e < f with Pₑ = Pf, meaning {α₁ᵉ,…,αₙᵉ} = {α₁ᶠ,…,αₙᶠ} as multisets. In particular α^e = αᵢᶠ for some i. Tracing the Galois action shows that α^(f − e) = 1."

<Problem
  client:load
  id="an53-prob-abs-value-one-not-root-unity"
  difficulty="standard"
  prompt="Is there an algebraic integer with absolute value 1 which is not a root of unity?"
  solution="Yes. Kronecker's theorem shows that IF all conjugates of α have absolute value 1, THEN α is a root of unity. But an algebraic integer can have |α| = 1 without all conjugates having absolute value 1. Example: let α be a root of x² − x − 1 = 0, so α = (1 ± √5)/2. The golden ratio φ = (1 + √5)/2 has |φ| ≈ 1.618 ≠ 1. But one can construct quadratic units of norm ±1 on the unit circle. More explicitly: take any algebraic integer α with |α| = 1 whose conjugate α' satisfies |α'| ≠ 1 — then α is not a root of unity. For instance, a Salem number on the unit circle serves as an example. So the answer is YES, such algebraic integers exist."
/>

  solution="No. The ring ℤ̄ of all algebraic integers is NOT Noetherian. Consider the ascending chain of ideals (2^(1/1)) ⊊ (2^(1/2)) ⊊ (2^(1/4)) ⊊ (2^(1/8)) ⊊ ⋯ in ℤ̄. Each inclusion is strict: 2^(1/2n) is not in the ideal generated by 2^(1/n), because 2^(1/2n)/2^(1/n) = 2^(-1/2n) satisfies x^(2n) = 1/2, so its minimal polynomial over ℚ has non-integer constant term, making it NOT an algebraic integer. Thus no element of ℤ̄ times 2^(1/n) equals 2^(1/2n), so the chain is strictly ascending and does not stabilize. Therefore ℤ̄ is not Noetherian."
