<SlideLayout title="Gauss's lemma — a practical shortcut">

Testing whether $\alpha$ is an algebraic integer via the *minimal* polynomial requires you to check minimality. Gauss's lemma gives a much more convenient criterion.

<Callout kind="proposition" title="Gauss's lemma (practical form)">
$\alpha$ is an <Term k="algebraicInteger">algebraic integer</Term> if and only if $\alpha$ is the root of **some** monic polynomial with integer coefficients — it need not be the minimal one.
</Callout>

This makes it easy to check $\sqrt{2} + \sqrt{3}$: we just need to exhibit *any* monic integer polynomial that kills it. The polynomial $(x^2 - 5)^2 - 24$ works (check: if $x = \sqrt{2}+\sqrt{3}$ then $x^2 = 5 + 2\sqrt{6}$, so $x^2 - 5 = 2\sqrt{6}$, so $(x^2-5)^2 = 24$), so $\sqrt{2}+\sqrt{3}$ is an algebraic integer — done.
