<SlideLayout title="The Cantor set has measure zero">

Once we have the Lebesgue measure, we can compute — often without worrying about how it was built.

<Callout kind="example" title="The Cantor set has measure zero">
The <Term k="cantorSet">**middle-thirds Cantor set**</Term> $C \subseteq [0,1]$ is built by repeatedly removing the open middle third of each remaining interval:

- Remove $(1/3, 2/3)$ — leaves measure $2/3$
- Remove middles of what's left — leaves measure $(2/3)^2$
- After $n$ steps, the remaining set has measure $(2/3)^n$.

Since $(2/3)^n \to 0$, we get $\lambda(C) = 0$.
</Callout>

This is remarkable: $C$ is **uncountable** (its elements are ternary expansions avoiding the digit 1 — a bijection with $2^{\mathbb{N}}$), yet it has Lebesgue measure zero. Size as a set and size as a measure can diverge dramatically.

The measure computation is easy once we know the measure exists: we just track the measure at each step of the construction.
