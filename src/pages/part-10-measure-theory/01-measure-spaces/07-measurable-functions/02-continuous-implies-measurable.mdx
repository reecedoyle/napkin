<SlideLayout title="Continuous implies measurable">

The key inclusion: every continuous function is measurable (when both spaces carry their Borel $\sigma$-algebras).

<Callout kind="proposition" title="Continuous ⟹ Borel measurable">
Let $X$ and $Y$ be topological spaces with their Borel $\sigma$-algebras. If $f \colon X \to Y$ is continuous, then $f$ is <Term k="measurableFunction">measurable</Term>.
</Callout>

The proof is one sentence: a continuous function maps open preimages to open sets. Since $\mathcal{B}(Y)$ is generated by open sets of $Y$, and $f^{-1}$ of each open set is open (hence in $\mathcal{B}(X)$), the preimage $\sigma$-algebra contains all of $\mathcal{B}(Y)$.

<Callout kind="remark" title="Measurable need not be continuous">
The converse fails. There exist measurable functions that are nowhere continuous. The simplest example: the indicator function $\mathbf{1}_{\mathbb{Q}}$ (1 on rationals, 0 on irrationals) is measurable (since $\mathbb{Q}$ is a Borel set) but is discontinuous everywhere.

More subtly, there exist continuous functions with non-measurable preimages — but only when the preimage is of a **measurable** set under a continuous map that is not measure-theoretically "nice". The Devil's Staircase is the canonical example.
</Callout>

</SlideLayout>
