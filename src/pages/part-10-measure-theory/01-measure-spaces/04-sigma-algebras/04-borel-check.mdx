<SlideLayout title="Checking the Borel σ-algebra">

Let's verify a key fact about the <Term k="borelSigmaAlgebra">Borel $\sigma$-algebra</Term> $\mathcal{B}(\mathbb{R})$ on the real line, generated by all open sets.

<Callout kind="question" title="Are closed sets Borel?">
Show that every closed subset of $\mathbb{R}$ lies in $\mathcal{B}(\mathbb{R})$.
</Callout>

<ProofReveal
  client:load
  id="ms-sa-proof-closed-borel"
  prompt="Try it: a closed set is the complement of an open set. What does the σ-algebra axiom say about complements?"
  solution="A set F is closed if and only if its complement U = ℝ ∖ F is open. Since 𝒜 contains all open sets by assumption, it contains U. Since 𝒜 is closed under complements, it contains ℝ ∖ U = F. So every closed set F is in 𝒜 = ℬ(ℝ)."
/>

<Callout kind="remark" title="Why this matters">
Knowing that $\mathcal{B}(\mathbb{R})$ contains all open and all closed sets is enough for most of analysis. Any set you can describe by countable operations on intervals (unions, intersections, complements) is Borel measurable.
</Callout>
