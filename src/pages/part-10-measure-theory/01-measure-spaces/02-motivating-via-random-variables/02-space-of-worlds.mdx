The big idea in modern probability is to flip the script. Instead of starting with probabilities, we start with a **space of worlds**.

<Callout kind="definition" title="Worlds and random variables">
Our <Term k="measureSpace">measure space</Term> $\Omega$ is a set of **worlds**. Each element <Term k="omega">$\omega \in \Omega$</Term> is one complete description of reality. A <Term k="randomVariable">random variable</Term> is a function $X \colon \Omega \to \mathbb{R}$ — it reads off one number from each world.
</Callout>

This handles dependence automatically. If temperature $T(\omega)$ and rainfall $R(\omega)$ are both functions of the same world $\omega$, they can be as correlated as reality dictates — because reality is encoded in $\omega$.

A fair coin in this language: $\Omega = \{H, T\}$, and we want the "fraction" of worlds where the coin shows heads to be $\tfrac{1}{2}$. Assigning these fractions is the job of a **measure**.
