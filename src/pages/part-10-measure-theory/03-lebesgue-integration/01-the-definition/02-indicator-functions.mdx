The simplest function on a measure space is one that is 1 on some measurable set and 0 everywhere else.

<Callout kind="definition" title="Indicator function">
If $A$ is a measurable set of $\Omega$, the **indicator function** $\mathbf{1}_A \colon \Omega \to \mathbb{R}$ is defined by

$$\mathbf{1}_A(\omega) = \begin{cases} 1 & \omega \in A \\ 0 & \omega \notin A. \end{cases}$$
</Callout>

Think of $\mathbf{1}_A$ as a light switch: it is on precisely when $\omega$ is in $A$.

**Step 1.** For an indicator function, we require

$$\int_\Omega \mathbf{1}_A \; d\mu \defeq \mu(A)$$

which may be infinite. This is the only sensible choice: integrating a function that is 1 on $A$ and 0 elsewhere should give the measure of $A$.
