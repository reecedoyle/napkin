<SlideLayout title="Riemann integrability requires boundedness">

A key limitation of the Riemann integral is that every Riemann integrable function *must be bounded*. The Lebesgue theory handles many unbounded functions with no trouble.

<Callout kind="example" title="A function that is not Riemann integrable on [0,1]">
Define

$$f(x) = \begin{cases} \dfrac{\sin(1/x)}{x} & x > 0 \\ 0 & x = 0. \end{cases}$$

This function blows up as $x \to 0$, so it is **not** bounded on $[0,1]$, and hence **not Riemann integrable** on $[0,1]$.

The improper Riemann integral $\lim_{\varepsilon \to 0^+} \int_\varepsilon^1 f(x) \; dx$ may still exist as a limit — but that is a different object than the Riemann integral.
</Callout>
