  prompt="(Alternating series test) Let $a_0 \ge a_1 \ge a_2 \ge \cdots$ be a weakly decreasing sequence of nonneg­ative real numbers with $\lim_{n\to\infty} a_n = 0$. Show that $\sum_n (-1)^n a_n$ converges (it need not converge absolutely)."
  solution="We use the Cauchy criterion. For M ≤ N both even (the other cases are identical), the partial tail sum satisfies: aₘ − aₘ₊₁ + aₘ₊₂ − ⋯ ≤ aₘ (group pairs from the right: each is non-negative). On the other side, aₘ − aₘ₊₁ + ⋯ ≥ −aₘ₊₁ (group pairs from the left). So |∑_{n=M}^{N} (−1)ⁿ aₙ| ≤ aₘ. Since aₙ → 0, for any ε > 0 we can choose M large enough that aₘ < ε, so the partial sums are Cauchy and the series converges."

  prompt="Let $(a_n)_{n \ge 1}$ and $(b_n)_{n \ge 1}$ be sequences with $a_1 \le a_2 \le \cdots \le 1000$ and $\sum_n b_n$ convergent. Prove that $\sum_n a_n b_n$ converges. (No absolute convergence assumed.)"
  hint="Write aₙ = x₁ + ⋯ + xₙ where xᵢ ≥ 0. This is the Abel summation technique."
  solution="Since (aₙ) is non-decreasing, write aₙ = x₁ + x₂ + ⋯ + xₙ with xᵢ ≥ 0 for i ≥ 2. Then ∑ |xᵢ| = A < ∞ (bounded variation). To show the partial sums of ∑ aₙbₙ are Cauchy: for any ε > 0, choose K so the tails of ∑ bₙ have absolute value < ε/A. For N > M ≥ K, swap the double sum to get |∑_{k=M}^N aₖbₖ| ≤ ∑_j |xⱼ| · |∑_{k≥max(j,M)} bₖ| < A · (ε/A) = ε."
