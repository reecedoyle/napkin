<SlideLayout title="Riemann integrable functions">

We defined $\int_a^b f$ for continuous $f$. But the limit of Riemann sums can exist for some discontinuous functions too.

<Callout kind="definition" title="Riemann integrable">
A function $f \colon [a,b] \to \mathbb{R}$ (not necessarily continuous) is <Term k="riemannIntegrable">**Riemann integrable**</Term> on $[a,b]$ if the limit
$$\lim_{\operatorname{mesh}(P) \to 0} S(f, P)$$
exists (independently of the choice of sample points), and we define $\int_a^b f(x)\,dx$ to be that limit.
</Callout>

Examples of Riemann integrable functions beyond continuous ones:
- **Monotone functions** on $[a,b]$ (bounded, finitely many jump discontinuities).
- **Piecewise continuous** functions (finitely many jump discontinuities).

Not every bounded function is Riemann integrable: the Dirichlet function $\mathbf{1}_\mathbb{Q}$ (1 on rationals, 0 on irrationals) is not, because Riemann sums can be made to give any value in $[0,1]$.

<Callout kind="remark">
We won't use this extended definition much. The Lebesgue integral handles discontinuous functions far more cleanly, and every Riemann integrable function is also Lebesgue integrable.
</Callout>
