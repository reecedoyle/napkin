  solution="ℤₚ is sequentially compact: given (xⁿ) in ℤₚ, infinitely many share the same residue mod p (pigeonhole), so pass to that subsequence; repeat mod p², then p³, etc., extracting a diagonal subsequence that converges. For non-compactness of ℚₚ: the open balls {x : |x|ₚ < pⁿ} for n = 1, 2, … cover ℚₚ but no finite subcollection does, since elements of arbitrarily large p-adic absolute value exist."

<Problem

  difficulty="daggered"
  prompt="Show that both ℤₚ and ℚₚ are totally disconnected: the only connected subsets are the empty set and singleton sets."
  hint="Show that for any two distinct points x ≠ y there is a clopen (simultaneously open and closed) set containing x but not y. Use a ball of radius |x − y|ₚ / 2."
  solution="Let x ≠ y in ℤₚ (the same argument works for ℚₚ). Let r = |x − y|ₚ > 0. The open ball B(x, r) = {z : |z − x|ₚ < r} is clopen in the ultrametric topology (every open ball is also closed), contains x, and does not contain y. So {x} is separated from {y} by a clopen set. Any subset with more than one point can be similarly disconnected, so the connected components are singletons."
