<SlideLayout title="Reading off coefficients by differentiating">

We know $\frac{1}{1-x} = 1 + x + x^2 + \cdots$ for $|x| < 1$. But suppose we didn't — how would we find the coefficients $a_n$ in

$$\frac{1}{1-x} = a_0 + a_1 x + a_2 x^2 + a_3 x^3 + \cdots$$

**Step 1:** Plug in $x = 0$. We get $a_0 = 1$.

**Step 2:** Differentiate both sides. The left side gives $(1-x)^{-2}$; the right side gives $a_1 + 2a_2 x + 3a_3 x^2 + \cdots$. Plug in $x = 0$ again: $a_1 = 1$.

**Step 3:** Differentiate again. Each derivative shifts the coefficients — the pattern forces $a_n = 1$ for all $n$.

<Callout kind="remark" title="Key takeaway">
If a function equals a power series, its coefficients are completely determined by its derivatives at 0: $a_n = f^{(n)}(0)/n!$. We can always *compute* the series; the hard question is whether it *converges to* $f$.
</Callout>
