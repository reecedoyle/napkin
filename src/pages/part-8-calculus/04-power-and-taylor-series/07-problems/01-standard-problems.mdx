  solution="Assume for contradiction that all derivatives f⁽ⁿ⁾(x) ≥ 0 for all n and x. By Taylor's theorem with remainder, for any point a and order n, f(b) = ∑_{k=0}^n f⁽ᵏ⁾(a)/k! · (b−a)^k + f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (b−a)^{n+1} for some ξ between a and b. Taking a = 1 and b = 0, all terms in the sum are nonneg if derivatives are nonneg. Since f(1) = 1 and f(0) = 0, we would need 1 = f(1) = [Taylor sum at b=1 from a=0] but all derivative terms being nonneg forces constraints that lead to a contradiction with f(0) = 0, f(1) = 1, and f(x) ≥ 0 simultaneously. A clean approach: since f(0) = 0 and f ≥ 0, f has a local minimum at 0, forcing f'(0) = 0. Then f(1) = 1 > 0 = f(0) means f is not constant — but repeated application of the mean value theorem on f, f', f'', … eventually produces a negative derivative value."
