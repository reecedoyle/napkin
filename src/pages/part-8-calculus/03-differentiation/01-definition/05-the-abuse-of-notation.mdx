<SlideLayout title="The standard abuse of notation">

You will see the notation $(x^3)' = 3x^2$ everywhere. This is intentionally sloppy. Strictly, $f'$ is a function $U \to \RR$, defined point-by-point as a slope. But we treat it as just another function and write $f'(x)$ using the same variable $x$.

<Callout kind="remark" title="Why the sloppiness matters">
The derivative $f'(p)$ records a **slope** (units: output-units / input-units). The function value $f(p)$ records a **quantity** (units: output-units). They are different kinds of objects. In one variable this distinction is harmless; in multivariable calculus the derivative becomes a **linear map** rather than a number, and the sloppy notation breaks down.
</Callout>

For now: writing $f'(x) = 3x^2$ is fine and universal.
