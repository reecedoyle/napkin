<SlideLayout title="Smooth vs analytic">

The hierarchy of "niceness" for real functions is:

$$\text{analytic} \;\subset\; \text{smooth} \;\subset\; \text{differentiable} \;\subset\; \text{continuous}$$

Each inclusion is strict.

<Callout kind="remark" title="Why this matters">
In complex analysis (over ℂ), the situation is completely different: a once-differentiable complex function is automatically analytic. Over ℝ, differentiability and analyticity are genuinely different conditions. The example $f(x) = e^{-1/x}$ (for $x > 0$) is the canonical witness.
</Callout>

The function $f(x) = |x|$ witnesses that continuous does not imply differentiable (it fails at $x = 0$). Higher calculus and PDE theory care deeply about exactly which level of smoothness a function has.
