<SlideLayout title="Zero-forms are smooth functions">

A differential $0$-form on $\mathbb{R}^n$ is just a smooth function — it has no indices to contract with tangent vectors. On a manifold the definition is especially clean.

A $0$-form on $M$ is a collection of smooth functions $f_i \colon E_i \to \mathbb{R}$, one per chart, satisfying $f_j = f_i \circ \phi_{ij}^{-1}$ on overlaps. But this is exactly the same as saying there is a single smooth function $f \colon M \to \mathbb{R}$.

<Callout kind="proposition" title="0-forms = smooth functions">
A differential $0$-form on a smooth manifold $M$ is the same thing as a smooth function $f \colon M \to \mathbb{R}$.
</Callout>

This is the content of the chapter's problem: a $0$-form on $M$ is equivalent to a smooth function $M \to \mathbb{R}$.
