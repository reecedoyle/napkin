<SlideLayout title="0-forms — functions on points">

Start with the simplest case: a **0-form** is just a smooth function $f \colon U \to \mathbb{R}$. It assigns a real number to each point.

<Callout kind="definition" title="0-form">
A <Term k="zeroForm">**$0$-form**</Term> $f$ on $U$ is a smooth function $f \colon U \to \mathbb{R}$.
</Callout>

To "integrate" $f$ over a discrete set $S = \{p_1, p_2, \ldots\}$ of points, we simply sum the values:
$$\int_S f = f(p_1) + f(p_2) + \cdots$$

A 0-form lets us integrate over **0-dimensional cells** (finite sets of points). This is the degenerate case — interesting integration happens in higher dimensions.
