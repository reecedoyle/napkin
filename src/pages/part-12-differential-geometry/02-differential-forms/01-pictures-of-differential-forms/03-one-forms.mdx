<SlideLayout title="1-forms — linear functionals along curves">

We want to integrate over **curves** — 1-dimensional paths. A curve $c \colon [0,1] \to U$ traces out a path through $U$. At each point $p$ on the curve, we also have a tangent vector $v = c'(t)$.

To assign a number to "integrate along $c$", we need something that uses both the position $p$ and the direction $v$. A **1-form** does exactly this.

<Callout kind="definition" title="1-form">
A <Term k="oneForm">**$1$-form**</Term> $\alpha$ on $U$ is a smooth function
$$\alpha \colon U \to V^\vee.$$
At each point $p$, the value $\alpha_p \in V^\vee$ is a <Term k="linearFunctional">linear functional</Term> on tangent vectors.
</Callout>

So $\alpha_p(v) \in \mathbb{R}$ for each tangent vector $v \in V$. The linearity requirement — $\alpha_p(\lambda v) = \lambda\,\alpha_p(v)$ — is what makes integration over curves well-behaved.

The 1-form $\alpha$ "reads off" a number from every (point, tangent vector) pair along the curve. Summing these up gives $\int_c \alpha$.
