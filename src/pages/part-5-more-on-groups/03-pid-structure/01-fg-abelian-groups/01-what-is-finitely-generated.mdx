<SlideLayout title="Finitely generated abelian groups — what are they?">

An <Term k="abelianGroup">abelian group</Term> $(G, +)$ is **finitely generated** if it can be described by a finite list of generators: every element can be reached by combining them with integer coefficients.

<Callout kind="definition" title="Finitely generated abelian group">
An abelian group $G = (G, +)$ is <Term k="fgAbelian">**finitely generated**</Term> if there exist $b_1, \dots, b_m \in G$ such that every $x \in G$ can be written
$$x = c_1 b_1 + \dots + c_m b_m \quad c_i \in \ZZ.$$
</Callout>

Thinking of $G$ as a <Term k="ZZmodule">$\ZZ$-module</Term>, "finitely generated as an abelian group" is exactly "finitely generated as a $\ZZ$-module".

**Five quick examples:**

- $\ZZ$ is generated by $\{1\}$.
- $\Zc{n}$ is generated by $\{1\}$.
- $\ZZ^{\oplus 2}$ is generated by $(1,0)$ and $(0,1)$.
- $\ZZ^{\oplus 3} \oplus \Zc{9} \oplus \Zc{2016}$ is generated by five elements.
- $\Zc{3} \oplus \Zc{5}$ can be generated by just **one** element (see the exercise below).

The examples look suspiciously like direct sums of $\ZZ$'s and $\Zc{n}$'s. This is not a coincidence.
