<SlideLayout title="The center Z(G)">

<Callout kind="definition" title="Center">
The <Term k="centerGroup">**center**</Term> of a group $G$ is
$$Z(G) \defeq \{ x \in G \mid gx = xg \text{ for all } g \in G \}.$$
It is the set of elements that commute with every element of $G$.
</Callout>

The center is a subgroup of $G$, and it is always **normal** in $G$ (since $g \cdot Z(G) \cdot g^{-1} = Z(G)$).

Under the conjugation action, $Z(G)$ is exactly the set of elements whose conjugacy class has size 1 — elements fixed by every conjugation. The orbit-stabilizer theorem confirms this: $|\mathcal{O}_x| = |G|/|C_G(x)| = 1 \iff C_G(x) = G \iff x \in Z(G)$.

<Callout kind="corollary" title="Abelian groups have trivial conjugacy classes">
If $G$ is abelian, then $ghg^{-1} = h$ for all $g, h$, so every conjugacy class has size 1. Equivalently, $Z(G) = G$.
</Callout>
