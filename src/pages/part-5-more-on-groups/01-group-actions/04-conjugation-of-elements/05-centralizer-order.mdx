<Callout kind="definition" title="Centralizer">
The <Term k="centralizer">**centralizer**</Term> of $h \in G$ is
$$C_G(h) \defeq \{ x \in G \mid xh = hx \}.$$
It is the stabilizer of $h$ under conjugation, hence a subgroup of $G$.
By orbit-stabilizer, the size of the conjugacy class of $h$ is $|G|/|C_G(h)|$.
</Callout>

Elements in the same conjugacy class have the same order. To see why: if $h' = ghg^{-1}$ then ${h'}^n = g h^n g^{-1}$, so $h^n = 1 \iff {h'}^n = 1$.
