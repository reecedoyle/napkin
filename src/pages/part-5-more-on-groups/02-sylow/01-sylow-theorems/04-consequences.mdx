<SlideLayout title="Consequences of the Sylow theorems">

The Sylow theorems have several immediate corollaries that are useful in practice.

<Callout kind="corollary">
- A Sylow $p$-subgroup is <Term k="normalSubgroup">normal</Term> if and only if <Term k="sylowNp">$n_p = 1$</Term>.
- If $|G| = pq$ with $p < q$ both prime, then $n_q = 1$ (so $G$ has a normal subgroup of order $q$).
- Any abelian group has exactly one Sylow $p$-subgroup for each prime $p$ dividing $|G|$.
- If $p \neq q$, then a Sylow $p$-subgroup and a Sylow $q$-subgroup intersect only in the identity.
</Callout>

The second point is worth seeing concretely: if $|G| = pq$ with $p < q$, then $n_q \equiv 1 \pmod{q}$ and $n_q \mid p$. Since $q > p$, the only value satisfying both is $n_q = 1$.
