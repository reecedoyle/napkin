<SlideLayout title="Example — the non-holomorphic form z̄ dz">

Here is a subtler example: $\ol{z}\,dz$. The form is written as $f(z)\,dz$ with $f(z) = \ol{z}$.

Since $f(z) = \ol{z}$ is **smooth** (infinitely differentiable as a real map) but **not holomorphic**, this form is:
- <Term k="rs50type10">Type $(1,0)$</Term>: yes, because it is written as $f(z)\,dz$
- Holomorphic: no, because $f = \ol{z}$ is not holomorphic

<Callout kind="remark" title="The distinction between type and holomorphicity">
Both $2z\,dz$ and $\ol{z}\,dz$ are type $(1,0)$ — they share the same "rotation behavior." But only $2z\,dz$ is holomorphic, because only its coefficient $2z$ is holomorphic.

Type $(1,0)$ is a broader class: it only requires the coefficient $f$ to be smooth. Holomorphic forms are the type $(1,0)$ forms with a holomorphic coefficient.
</Callout>
