<Callout kind="example" title="A line bundle morphism that is not an isomorphism">
Let $X = \mathbb{C}$. Define $\alpha \colon \mathbb{C} \times X \to \mathbb{C} \times X$ by
$$\alpha(y, x) = (y \cdot x^2,\, x).$$

This is a <Term k="rs52lineBundleMorphism">line bundle morphism</Term>: it is fiber-preserving (the second coordinate $x$ is unchanged), and in the global chart the scaling function is $f(x) = x^2$, which is analytic on $\mathbb{C}$.

However, $\alpha$ is **not** an isomorphism. The scaling function $f(x) = x^2$ vanishes at $x = 0$. Every point $(y, 0)$ in the fiber above $0 \in X$ gets sent to $(0, 0)$, so $\alpha$ is not injective on the fiber at $0$.
</Callout>
