<SlideLayout title="Nontriviality and global sections">

We built a bundle over $\mathbb{C}_\infty$ whose real-part picture is a Möbius strip. It appears obviously <Term k="rs52nontrivialBundle">nontrivial</Term> — whatever "isomorphic" means, a Möbius strip and a cylinder are not the same.

<Callout kind="remark" title="Why nontriviality matters">
A line bundle is trivial if and only if it has a **nowhere-zero global (analytic) section**: such a section identifies each fiber with $\mathbb{C}$ consistently, giving an isomorphism to $\mathbb{C} \times X$. For the trivial bundle the constant section $p \mapsto (1, p)$ is nowhere zero. So nontriviality means precisely that *no* global section avoids zero everywhere. On the real Möbius bundle the sign flips as you loop around the base, so any global section must cross zero.

Over the complex Riemann sphere the bundle we built has no nowhere-zero global holomorphic section either (its nonzero global sections each vanish at a point), so it too is nontrivial.
</Callout>

Over ℂ the overlap ℂ \ {0} is connected, so there is no such freedom. The obstruction is the winding number: any nowhere-zero analytic function on ℂ \ {0} has a well-defined integer winding number n = (1/2πi)∮ f'/f around the origin, and it is trivializable across the origin only when n = 0. The transition function here has nonzero winding number, and no choice of nowhere-zero a and b can cancel it — so the twist is genuine."
