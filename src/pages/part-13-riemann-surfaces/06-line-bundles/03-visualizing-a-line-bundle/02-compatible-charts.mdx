<SlideLayout title="Compatible charts">

Two different-looking grids can represent the **same** line bundle structure.

Consider $U = \{z \in \mathbb{C} \mid |z - 3| < 2\}$, whose real part is the open interval $(1, 5)$.

**Reparametrizing the base.** If we apply the analytic change of coordinate $t = 25/x$ to the interval, the vertical grid lines move. But this only changes how we label points on $X$, not the fiber structure — the two charts are compatible.

**Rescaling the fiber by an analytic function.** If we scale the vertical direction by a function $g(x)$ that is analytic and nonzero on $(1, 5)$, the fiber isomorphism changes, but the underlying line bundle does not.

<Callout kind="remark" title="What is NOT compatible">
If we rescale the vertical direction by a function that is **not** linear on each fiber — for example, replacing the $y$-coordinate by $|y|^{0.7} \cdot \mathrm{sgn}(y)$ — the vector space structure changes. The two grids no longer represent the same line bundle structure, because adding two fiber elements and then rescaling gives a different answer than rescaling then adding.
</Callout>
