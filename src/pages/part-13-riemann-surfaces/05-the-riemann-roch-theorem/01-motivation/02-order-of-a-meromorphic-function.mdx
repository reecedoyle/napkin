<SlideLayout title="Order of a meromorphic function">

To interpolate between "no poles allowed" and "arbitrary poles allowed" we need to measure how badly a meromorphic function blows up at each point. The <Term k="rs51ordP">order $\ord_p(f)$</Term> packs this into a single integer.

<Callout kind="definition" title="Order of a meromorphic function at p">
Let $f$ be meromorphic at $p$. Define

$$
\ord_p(f) = \begin{cases}
  d & \text{if } f \text{ has a zero of multiplicity } d \text{ at } p, \\
  -d & \text{if } f \text{ has a pole of order } d \text{ at } p, \\
  0 & \text{otherwise.}
\end{cases}
$$
</Callout>

Zeros contribute positive order; poles contribute negative order. The function $\ord_p$ is like a signed multiplicity that treats zeros and poles uniformly.
