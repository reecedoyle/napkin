<SlideLayout title="Complex charts on affine curves">

The implicit function theorem does more than guarantee smoothness — it hands us local coordinates. These become the <Term k="rs49complexChart">**complex charts**</Term> that make the curve a Riemann surface.

On an open set $U \subseteq X$ where $\frac{\partial f}{\partial z} \neq 0$ everywhere, the curve is locally parametrised by $z = g(w)$, so the map $\phi(z, w) = w$ is a valid complex chart from $U$ to $\mathbb{C}$.

On an open set where $\frac{\partial f}{\partial w} \neq 0$ everywhere, use $\phi(z, w) = z$ instead.

<Callout kind="remark" title="These charts are compatible">
Where both derivatives are nonzero, the two charts overlap and the transition map is holomorphic — this is what it means for them to define a complex structure.
</Callout>

**Check on the unit circle.** For $f(z,w) = z^2 + w^2 - 1$, we get $\partial f/\partial z = 2z$ and $\partial f/\partial w = 2w$. At the point $(0, 1)$ we have $\partial f/\partial z = 0$ but $\partial f/\partial w = 2 \neq 0$, so the chart $\phi = z$ works near $(0,1)$. At $(1, 0)$ it's reversed.
