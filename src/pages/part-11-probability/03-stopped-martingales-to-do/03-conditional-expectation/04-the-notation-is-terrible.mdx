<Callout kind="remark" title="The notation 𝔼(X | ℱ) is confusing">
$\mathbb{E}(X \mid \mathcal{F})$ looks like a number — it has the same shape as $\mathbb{E}[X]$. But it is actually an entire function $\Omega \to \mathbb{R}$. To flag this distinction, Napkin uses parentheses for conditional expectations and square brackets for ordinary expectations.
</Callout>

<Callout kind="remark" title="Almost-sure uniqueness">
When we write $Y = \mathbb{E}(X \mid \mathcal{F})$, there is a hidden "up to measure zero" clause. Two functions satisfying the conditions of the proposition may differ on a set of measure zero — and that's fine, because any $\mathcal{F}$-measurable modification on a measure-zero set still satisfies the defining equation.
</Callout>

**Worked example.** For $X, Y$ independent and uniform on $[0,1]$, we claimed $\mathbb{E}(X \mid X+Y) = \frac{X+Y}{2}$.
