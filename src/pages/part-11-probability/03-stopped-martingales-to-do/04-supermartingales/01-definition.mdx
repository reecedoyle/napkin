With conditional expectation in hand, we can define the central objects of this chapter.

<Callout kind="definition" title="Supermartingale / Submartingale / Martingale">
Let $(X_n)_{n \ge 0}$ be a sequence of random variables on $\Omega$, and let $\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \cdots$ be a filtration. The sequence is:

- A **<Term k="supermartingale">supermartingale</Term>** if each $X_n$ is absolutely integrable, $X_n$ is $\mathcal{F}_n$-measurable, and $\mathbb{E}(X_n \mid \mathcal{F}_{n-1}) \le X_{n-1}$ a.e. for all $n \ge 1$.
- A **<Term k="submartingale">submartingale</Term>** if the same holds with $\ge$ instead of $\le$.
- A **<Term k="martingale">martingale</Term>** if equality holds: $\mathbb{E}(X_n \mid \mathcal{F}_{n-1}) = X_{n-1}$ a.e.
</Callout>

We will nearly always take $\mathcal{F}_n = \sigma(X_0, X_1, \dots, X_n)$ — the natural filtration generated by the process — and drop further mention of it. All theorems extend to the more general setting.

**Symmetry.** $(X_n)$ is a martingale if and only if it is both a supermartingale and a submartingale. And $(-X_n)$ is a supermartingale exactly when $(X_n)$ is a submartingale.
