<Callout kind="example" title="Random walk is a martingale">
An ant starts at $0$ and each minute moves $+1$ or $-1$ with equal probability. If $X_t$ is its position at time $t$, then

$$\mathbb{E}(X_t \mid X_0, \dots, X_{t-1}) = \frac{(X_{t-1}+1) + (X_{t-1}-1)}{2} = X_{t-1}.$$

So the symmetric random walk is a martingale.
</Callout>

<Callout kind="example" title="Casino game is a martingale">
The doubling strategy from §1 is a martingale: every individual bet has expected value $0$, so wealth has the same expected value before and after each bet.
</Callout>

<Callout kind="example" title="Product of mean-1 variables is a martingale">
Let $X_1, X_2, \dots$ be independent with $\mathbb{E}[X_i] = 1$. Then $Y_n = X_1 X_2 \cdots X_n$ is a martingale, since $\mathbb{E}(Y_n \mid Y_1, \dots, Y_{n-1}) = \mathbb{E}[X_n] \cdot Y_{n-1} = Y_{n-1}$.
</Callout>

<Callout kind="example" title="Blackjack is a supermartingale">
If $X_t$ is your wealth after $t$ games of blackjack, the house edge makes $\mathbb{E}(X_t \mid X_0, \dots, X_{t-1}) < X_{t-1}$. Your expected wealth can only decrease.
</Callout>
