<Callout kind="theorem" title="Doob's optional stopping theorem">
Let $(X_n)$ be a supermartingale and $\tau$ a stopping time. Suppose any **one** of the following holds for some constant $C$:

**(a) Finite time.** $\tau(\omega) \le C$ for almost all $\omega$.

**(b) Finite money.** $|X_{\tau \wedge n}(\omega)| \le C$ for all $n$ and almost all $\omega$.

**(c) Finite bets.** $\mathbb{E}[\tau] < \infty$, and $\mathbb{E}(|X_n - X_{n-1}| \mid \mathcal{F}_n) \le C$ a.e. on $\{\tau \ge n\}$.

Then $X_\tau$ is well-defined almost everywhere, and

$$\mathbb{E}[X_\tau] \le \mathbb{E}[X_0].$$
</Callout>

The last equation can be cheekily expressed as: **the only winning move is not to play**.

The <Term k="optionalStopping">optional stopping theorem</Term> tells us that no stopping strategy can extract profit from a supermartingale (under sane conditions). The doubling strategy from §1 violates all three: it may run forever, the money needed is unbounded, and the bet size is unbounded.
