<Callout kind="corollary" title="Optional stopping for martingales">
Under the same hypotheses as Doob's theorem:

- If $(X_n)$ is a **submartingale**, then $\mathbb{E}[X_\tau] \ge \mathbb{E}[X_0]$.
- If $(X_n)$ is a **martingale**, then $\mathbb{E}[X_\tau] = \mathbb{E}[X_0]$.
</Callout>

**Proof.** For a submartingale, apply the theorem to $(-X_n)$, which is a supermartingale. For a martingale, it is both a supermartingale and a submartingale, so both inequalities apply and we get equality.

**Why equality is powerful.** For a supermartingale we only know $\mathbb{E}[X_\tau] \le \mathbb{E}[X_0]$. But for a martingale we get the precise equation $\mathbb{E}[X_\tau] = \mathbb{E}[X_0]$. If we know $\mathbb{E}[X_0]$ and can compute $\mathbb{E}[X_\tau]$ in terms of what we want to find — we can solve for the unknown!
