<Callout kind="definition" title="Sub-σ-algebra">
Let $\Omega = (\Omega, \mathcal{A}, \mu)$ be a probability space. A **sub-$\sigma$-algebra** $\mathcal{F}$ on $\Omega$ is a $\sigma$-algebra on the set $\Omega$ such that $\mathcal{F} \subseteq \mathcal{A}$ — every $\mathcal{F}$-measurable set is also $\mathcal{A}$-measurable.
</Callout>

The idea: $\mathcal{F}$ is the collection of events we can ask about given our current information. Two key examples:

**Discrete random variable.** If $X \colon \Omega \to \{0,1,2\}$, define $A = \{X=0\}$, $B = \{X=1\}$, $C = \{X=2\}$. Then

$$\mathcal{F} = \{ \varnothing,\, A,\, B,\, C,\, A\cup B,\, B\cup C,\, C\cup A,\, \Omega \}$$

is a sub-$\sigma$-algebra encoding everything $X$ tells us.

**Continuous random variable.** If $Y \colon \Omega \to [0,1]$, the sub-$\sigma$-algebra capturing $Y$ is

$$\mathcal{F} = \{ Y^{-1}(B) \mid B \subseteq [0,1] \text{ measurable} \}.$$

Both examples fit the same general pattern: the <Term k="sigmaGeneratedBy">$\sigma$-algebra generated by $X$</Term>.
