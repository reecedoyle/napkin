(a) Show that $\rho \colon \mathrm{Reg}(A) \to \Mat(V)$ is an intertwining operator. (b) If $V$ is $d$-dimensional, show that $\Mat(V) \cong V^{\oplus d}$ as representations of $A$."

So ρ intertwines the left-multiplication action on Reg(A) with the action on Mat(V). (b) Fix a basis e₁, …, e_d of V. Define Φ: Mat(V) → V^⊕d by Φ(T) = (T(e₁), …, T(e_d)). This is a linear isomorphism of vector spaces. It intertwines: Φ(a·T) = Φ(ρ(a)∘T) = (ρ(a)T(e₁), …, ρ(a)T(e_d)) = a·(T(e₁), …, T(e_d)) = a·Φ(T)."

  solution="The intertwining operators are exactly the right-multiplication maps T_b: a ↦ ab for some fixed b ∈ A. To check: T_b(c·a) = T_b(ca) = cab = c·(ab) = c·T_b(a). To see these are all: for any intertwining T, we have T(a) = T(a·1_A) = a·T(1_A), so T is right multiplication by b = T(1_A)."
