<SlideLayout title="Galois extensions, defined">

We now have exactly the vocabulary needed to state when a field extension is "not deficient."

<Callout kind="theorem" title="Galois extensions are splitting">
For finite extensions $K/F$, $|\Aut(K/F)|$ divides $[K:F]$, with equality if and only if $K$ is the splitting field of some separable polynomial with coefficients in $F$.
</Callout>

The proof is deferred to the optional §7 at the end of this chapter.

<Callout kind="definition" title="Galois extension">
If $K/F$ is a finite extension and $|\Aut(K/F)| = [K:F]$, we say $K/F$ is <Term k="gal58GaloisExtension">Galois</Term>. In that case we write $\Aut(K/F)$ as $\Gal(K/F)$ instead, and call it the **Galois group** of $K/F$.
</Callout>

This is precisely the "not deficient" condition we've been chasing since §1: $\QQ(\sqrt2)$ and $\QQ(i)$ satisfied it ($|\Aut| = [K:\QQ]$), while $\QQ(\cbrt2)$ didn't ($1 \ne 3$).

</SlideLayout>
