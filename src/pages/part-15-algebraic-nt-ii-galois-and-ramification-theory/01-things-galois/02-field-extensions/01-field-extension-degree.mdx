Everything in §1 was really about number fields — extensions of $\QQ$ specifically. Let's generalize: one field can sit inside another, with no requirement that the smaller one be $\QQ$.

<Callout kind="definition" title="Field extension, degree">
Let $K$ and $F$ be fields. If $F \subseteq K$, we write <Term k="gal58FieldExtension">$K/F$</Term> and say $K$ is a field extension of $F$. Since $F \subseteq K$, $K$ is automatically an $F$-vector space (just like $\QQ(\sqrt2)$ is automatically a $\QQ$-vector space). The <Term k="gal58ExtensionDegree">degree</Term> $[K:F]$ is the dimension of this vector space. If $[K:F]$ is finite, $K/F$ is a **finite extension**.
</Callout>

That's really all there is — nothing tricky. A number field, as we've been using the term, is exactly a finite extension of $\QQ$.
