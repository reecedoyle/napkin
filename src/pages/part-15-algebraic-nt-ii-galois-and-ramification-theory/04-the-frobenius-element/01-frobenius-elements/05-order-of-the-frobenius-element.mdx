<Callout kind="lemma" title="Order of the Frobenius element">
Let $\Frob_\kp$ be a Frobenius element from an extension $K/\QQ$. Then <Term k="elementOrder">$\ord(\Frob_\kp)$</Term> equals the inertial degree $f_\kp$. In particular, $(p)$ splits completely in $\OO_K$ if and only if $\Frob_\kp = \id$.
</Callout>

This lemma is what lets us read off the splitting behavior of $\kp$ just by computing $\Frob_\kp$ — a trick we'll reuse constantly, most dramatically in the cyclotomic-field example and the quadratic reciprocity proof coming up.

  solution="The decomposition group D_𝔭 (automorphisms of K fixing 𝔭 as a set) maps isomorphically onto Gal((𝒪_K/𝔭)/𝔽_p) when p is unramified, and this isomorphism sends Frob_𝔭 to the map T: x ↦ x^p on 𝔽_{p^f}. The Galois group Gal(𝔽_{p^f}/𝔽_p) is cyclic of order f, generated by T — that's a standard fact about finite fields. So T has order exactly f, and since the map D_𝔭 → Gal((𝒪_K/𝔭)/𝔽_p) is an isomorphism, Frob_𝔭 has the same order as its image T, namely f. Finally, (p) splits completely in 𝒪_K exactly when every prime above p has inertial degree 1, which (by this lemma) happens exactly when Frob_𝔭 = id for every such 𝔭."
