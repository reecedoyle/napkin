Before we can even claim $\partial([c]) = [a]$ makes sense as a homology class of $A_{n-1}$, we owe ourselves one basic sanity check: is $a$ actually a <Term k="tle71Cycle">cycle</Term>, i.e. is $\partial_A(a) = 0$?

  solution="Apply f_{n-2} to ∂_A(a). Since f is a chain map, f_{n-2} commutes with the boundary maps, so f_{n-2}(∂_A(a)) = ∂_B(f_{n-1}(a)). But f_{n-1}(a) = ∂_B(b) by construction, so this equals ∂_B(∂_B(b)) = 0, since ∂_B ∘ ∂_B = 0 for any chain complex. So f_{n-2}(∂_A(a)) = 0. Now f_{n-2} is injective (it's the left-hand map of a short exact row), so ∂_A(a) = 0 itself — meaning a really is a cycle, and [a] is a legitimate homology class in H_{n-1}(A_bullet)."
