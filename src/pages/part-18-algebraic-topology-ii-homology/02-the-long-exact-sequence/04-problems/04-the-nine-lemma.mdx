  solution="Index the three rows as degrees 2, 1, 0 from top to bottom, so the A-column becomes a three-term chain complex A_bullet with degree-2 term A_1, degree-1 term A_2, and degree-0 term A_3 (using the diagram's own row labels), with boundary maps given by the vertical arrows; likewise build B_bullet and C_bullet from the B-column and C-column. The hypothesis that every row is short exact says precisely that 0 → A_bullet → B_bullet → C_bullet → 0 is a short exact sequence of chain complexes, degree by degree. Apply the long exact sequence theorem to get an exact sequence linking H_n(A_bullet), H_n(B_bullet), H_n(C_bullet) for n = 0, 1, 2, and note that being an exact column is exactly the same statement as that column's chain complex having all homology groups zero. Suppose, say, the A-column and B-column are exact — so H_n(A_bullet) = 0 and H_n(B_bullet) = 0 for every n. The long exact sequence around degree n reads H_n(A_bullet) → H_n(B_bullet) → H_n(C_bullet) → H_{n-1}(A_bullet) → H_{n-1}(B_bullet), i.e. 0 → 0 → H_n(C_bullet) → 0 → 0, forcing H_n(C_bullet) = 0 for every n — so the C-column is exact too. The same argument works verbatim for any other pairing of two exact columns, by symmetry of the long exact sequence theorem in A, B, C."
