The last problem is the hardest — it pulls together functoriality, the product pseudo-ring rule, and the Künneth formula all at once.

<Problem
  client:load
  id="aoc75-prob-wedge-not-retract-of-product"
  prompt="Show that S^m ∨ S^n is not a deformation retract of S^m × S^n for any m, n ≥ 1."
  hint="Assume r: S^m × S^n → S^m ∨ S^n is such a map, with inclusion i: S^m ∨ S^n → S^m × S^n satisfying r∘i = id. Show that the induced map H^•(S^m ∨ S^n; ℤ) → H^•(S^m × S^n; ℤ) between cohomology rings is monic (injective), using that there exists an inverse-on-the-left map i."
  solution="Suppose such a retraction r existed, with i the inclusion satisfying r∘i = id on S^m∨S^n. Pulling back reverses composition order, so i*∘r* = id on H^•(S^m∨S^n;ℤ); in particular r* : H^•(S^m∨S^n;ℤ) → H^•(S^m×S^n;ℤ) is injective (it has a left inverse), and it is a ring homomorphism since it's induced by a continuous map. Let a be the generator of H^m(S^m∨S^n;ℤ) and b the generator of H^n(S^m∨S^n;ℤ). By the product-pseudo-ring rule for wedge sums, a and b come from different wedge factors, so a⌣b = 0. Since r* is a ring homomorphism, r*(a)⌣r*(b) = r*(a⌣b) = r*(0) = 0. But r* is injective and a, b are nonzero, so r*(a) and r*(b) are nonzero elements of H^m(S^m×S^n;ℤ) and H^n(S^m×S^n;ℤ). By Künneth, H^•(S^m×S^n;ℤ) ≅ H^•(S^m;ℤ)⊗H^•(S^n;ℤ), so H^m(S^m×S^n;ℤ) ≅ ℤ is generated by α⊗1 and H^n(S^m×S^n;ℤ) ≅ ℤ is generated by 1⊗β (α, β the respective sphere generators). So r*(a) = k(α⊗1) and r*(b) = l(1⊗β) for nonzero integers k, l, and then r*(a)⌣r*(b) = kl(α⊗β), which is nonzero since α⊗β generates the nonzero group H^{m+n}(S^m×S^n;ℤ) ≅ ℤ. This contradicts r*(a)⌣r*(b) = 0 from before. So no such retraction r can exist: S^m∨S^n is not a deformation retract of S^m×S^n."
